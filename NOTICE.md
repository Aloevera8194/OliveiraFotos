# Avisos de terceiros

O reconhecimento de rostos usa o modelo FaceNet em formato TensorFlow Lite (`facenet.tflite`),
baixado no momento da compilação do repositório
https://github.com/shubham0204/FaceRecognition_With_FaceNet_Android
(licença Apache 2.0, https://www.apache.org/licenses/LICENSE-2.0).
O modelo vem do projeto DeepFace / keras-facenet, conforme descrito no README desse repositório.

A detecção de rostos e a sugestão de assuntos usam o Google ML Kit.
